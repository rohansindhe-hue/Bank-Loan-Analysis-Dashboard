# Bank-Loan-Analysis-Dashboard
Bank Loan Analysis Project Description
Bank Loan Analysis & Dashboard

Developed an end-to-end Bank Loan Analysis project to analyze loan applications, borrower profiles, loan performance, and repayment trends using Excel, SQL, Power BI, and Tableau.

Used Excel for data cleaning, preprocessing, exploratory analysis, and identifying initial trends and patterns.
Used SQL to extract, transform, filter, and analyze loan data, generating meaningful business insights through queries and aggregations.
Built an interactive Power BI dashboard to track key loan KPIs such as total loan applications, funded amount, amount received, average interest rate, average DTI, good/bad loan performance, and loan status.
Created visualizations in Tableau to analyze loan distribution, borrower characteristics, repayment patterns, regional trends, and other business metrics.
Performed data-driven analysis to identify factors affecting loan performance and distinguish between good and bad loans.
Designed interactive dashboards with filters and drill-downs to enable users to explore the data and make informed business decisions.
Transformed raw loan data into meaningful insights and actionable recommendations that can support credit risk assessment and lending decisions.
